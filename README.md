# SmartHire AI

SmartHire AI is an intelligent resume analysis system that classifies resumes, calculates ATS scores, provides career insights, and recommends suitable jobs using Machine Learning.

## Features

- Resume Upload
- Resume Classification
- Resume Score
- ATS Score
- Career Insights
- Job Recommendation
- PDF Report Generation
- Interactive Dashboard

## Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- Scikit-Learn
- Pandas
- ReportLab
